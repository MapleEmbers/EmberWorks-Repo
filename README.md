# Ember Works Plugins

### Currant plugins
- Ember Delivery
- Ember Tweaks

## Activating in-game

1. In Dalamud settings, go to `Experimental` > `Custom Plugin Repositories`.
2. Add the repo `https://raw.githubusercontent.com/MapleEmbers/EmberWorks-Repo/main/pluginmaster.json`.
3. Click the `+` (Plus) to the right of the text field.
4. Click `Save`, the settings window should close itself.
5. Open the Plugin Installer (`/xlplugins`) and enable desired plugin under `All Plugins` > `Desired plugin` > `Install`.
